#Task Manager - Flutter Application
##Task Manager is a task management application built using Flutter and Dart. This project demonstrates my ability to build real-world applications, focusing on clean code, UI/UX design, and Flutter’s core features. The app provides a simple yet functional task management system.

🛠️ Technologies Used:
Flutter: A powerful framework for building cross-platform mobile applications (iOS & Android) with a single codebase.

Dart: The programming language used for developing the app, known for its performance and productivity.

intl: For date and time formatting, ensuring proper localization.

⚙️ Core Features:
Task Creation and Management: Users can create, edit, and delete tasks with essential details such as titles, descriptions, deadlines, and priority levels.

Task Categorization: Allows users to categorize tasks by priority, type, or deadlines, enabling better task organization.
